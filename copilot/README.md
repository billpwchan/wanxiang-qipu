# 万象副驾（局内教练，本机运行）

打游戏时不用在网页上填任何东西。Mac 读取 iPad 的镜像画面，自己认出商店、手牌、天赋、拍卖和选棋手界面，用语音告诉你「买韩信」「天赋选战术模组」「拍卖拿朵莉亚，最多 4 能量」，同时在 Mac（或手机）上显示一块大字面板。

![副驾面板](../docs/images/screen-copilot.webp)

判断和网站用同一套数据（`site/dist/data/plan.js` + `facts.js`）：路线、每个阶段买什么、拍卖出价上限都一样。

```
iPad 画面 ──USB/AirPlay──▶ Mac 窗口
  eye（Swift）：ScreenCaptureKit 抓窗口 → Apple Vision 中文 OCR（约 0.2 秒/帧，偏置 500 多个卡名）
  brain（Node）：认牌 → 判断界面 → 从手牌推断路线 → 按网站的路线数据给建议 → 语音 + HUD
  深想（可选）：把「文字局面」交给本机 claude CLI 做第二意见（约 10–20 秒）
```

全部在本机完成：不读游戏内存、不抓网络包、不点击屏幕，只看你本来就能看到的画面。

## 第一次使用（5 分钟）

需要 macOS 14+、Node 22+、Xcode 命令行工具（`xcode-select --install`，用来编译 eye）。

1. **给终端屏幕录制权限**：系统设置 → 隐私与安全性 → 屏幕与系统录音 → 打开你用的终端（Terminal / iTerm / Warp），然后重开终端。
2. **把 iPad 画面放到 Mac 上**，二选一：
   - **USB（推荐，延迟最低）**：USB-C 线连 iPad → 打开 QuickTime Player → 文件 → 新建影片录制 → 录制按钮旁的小箭头 → 摄像头选你的 iPad。窗口名叫「影片录制」。
   - **AirPlay（无线）**：Mac 系统设置 → 通用 → 隔空播放与接力 → 打开「隔空播放接收器」；iPad 控制中心 → 屏幕镜像 → 选这台 Mac。
3. **确认窗口名**：`./copilot/wx windows`
4. **启动**：`./copilot/wx`（默认找「影片录制」窗口），或 `./copilot/wx 隔空播放`。浏览器会自动打开面板 http://127.0.0.1:4174/ 。

常用参数：`--lan` 在手机上看面板（同一 Wi-Fi，会打印地址；面板没有鉴权，只在自己的网络里用）；`--no-voice` 关语音；`--save` 把每次变化的画面存到 `copilot/logs/frames/`（用于校准，见下）。

没开游戏想先看看：`./copilot/wx demo`（回放测试帧）。想停在某一帧看面板：`node copilot/brain.mjs demo copilot/test/frames.jsonl --until 7`。

## 它现在能做什么

| 画面 | 它读什么 | 它说什么 |
|---|---|---|
| 选棋手 | 三个棋手名、本局禁用 | 选谁、走哪条路线（和网站开局推荐同一个顺序） |
| 商店 | 商店卡名、手牌卡名、回合、能量 | 这个阶段该买哪张、为什么；升本回合钱不够时提醒先后顺序 |
| 天赋三选一 | 三个天赋名 | 按当前路线的必拿 / 可以拿 / 别拿排序（前两次升本优先能量类） |
| 拍卖 | 拍品卡名 | 拿哪件、出价上限 |

- **路线自动推断**：每张新出现在手牌里的英雄都记为「拿到一张」，结合棋手算出最可能的路线；本局禁用阵营打不了的路线不参与；面板上点一下可以锁定。
- **认牌有两路信号**：卡名（大字）和卡牌效果文字（每个英雄唯一）。卡名读不出来、或被截成「典娜」，也能靠描述认出来。
- **只在需要时说话**：同一建议 45 秒内不重复。

## 还需要你帮一次忙：校准

副驾只用官方卡面渲染模拟过画面（`copilot/test/`，8 步全过），没在真实游戏画面上校准过。真实游戏里商店和手牌的位置、回合和能量的显示方式可能不同。

打一局时加 `--save`，结束后按 [CONTRIBUTING.md](../CONTRIBUTING.md#提交副驾截帧) 提交截帧，据此写 `copilot/layout.json`（商店区、手牌区、能量和回合数字的位置），准确率会明显提高。在那之前：
- 商店区默认是画面上部 5–58%，手牌区是下部 68–100%；
- 回合和能量只在画面里出现「第 N 回合」「能量 N」这类文字时才读得到，面板上可以手动 ± 回合。

## 已知限制

- 场上棋子（3D 模型）没有名字文字，目前不认；路线靠手牌推断。
- 深想依赖本机 `claude` 命令，会消耗你的 Claude 用量；默认用 sonnet（`WX_MODEL=opus ./copilot/wx` 可换）。
- 腾讯没有公开允许第三方辅助。这个工具只读屏幕、不操作游戏，但在排位里使用仍有被判定违规的可能，风险自担。

## 测试

```sh
node copilot/test/run.mjs            # 渲染模拟画面 → OCR → 回放 → 检查 8 步建议（macOS）
node copilot/test/run.mjs --replay   # 只回放已提交的 OCR 结果（任何系统）
```

工作原理（认牌、界面判断、路线推断、打分）见 [docs/architecture.md](../docs/architecture.md#副驾copilot)。
