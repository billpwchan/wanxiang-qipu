# 王者万象棋 S1：从资源循环到逐回合决策

研究日期：2026-09-23。对象：标准万象大赛。本文是基于公开规则的策略研究与条件推演，没有运行游戏对局，也没有用假造的战斗结果、胜率或名次替代理论验证。

本次重新读取并审查了官方接口的 85 张普通英雄、19 位棋手、255 项天赋、73 件装备、98 张效果牌；另外追查关联卡，补入普通英雄列表之外的王维、图腾和召唤单位。重新抓取的数据与此前快照在去除媒体地址、关联来源排序后，规则字段一致。公开接口仍可能落后于客户端热更。

本文中的“优先”表示在给定条件下，我认为更值得投入的决策；不是实测强度榜。“推演局面”是明确给定来牌和资源的桌面演算，不代表实际抽牌概率，也不预先指定谁赢。

配套的[全英雄取舍与关键天赋](全英雄取舍与关键天赋.md)逐一解释了全部普通英雄为什么值得留、何时退出，以及特殊英雄、关键天赋和效果牌怎样改变决策。第21节继续推导几种不必重练整套阵容的组合改进。

## 1. 我的主要判断

真正值得研究的不是再创造几个七人阵容名字，而是找出：**同一笔投入能否触发多个独立收益；这些收益能否集中到会决定胜负的位置；原有投入能否在转型时保留下来。**

据此，我会把打法分成三类：

| 用途 | 优先研究的路线 | 理由 | 最重要的失败条件 |
|---|---|---|---|
| 少依赖五阶牌、提高单位投入收益 | 姜导逐鹿：镜 / 廉颇分叉 | 芈月、效果牌、低法力施法和姜导可叠加收益 | 只堆等级，没解决接战和首次施法 |
| 低阶起步、保留多个输出出口 | 三分施法：大乔、刘禅、马超，诸葛亮后接 | 训练好的低法力大乔是可持续资产，主核不必等五阶 | 开局施法链被切断，或对手免控 |
| 操作压力小、成长分散、转型代价较低 | 香香开团射 / 跨阵营张良 | 开团和普攻同时带来成长；主要部件在二三阶 | 为凑阵容卖掉已养成的有效前排 |
| 有低阶牌流时集中成长 | 马可同阶养成 | 买牌、合成、宝藏、同阶成长、夺取相互结合 | 买卖看似热闹，但能量实际上一直减少 |
| 已有自然整备底座 | 日落海先积累、后压缩分配 | 前期吃广泛成长，后期集中核心等级跨技能门槛 | 压缩过早，把前排和回蓝一起卖掉 |
| 成型后争上限 | 白歌三分倒转 / 玉环日落海刷牌 | 可以把牌流变成大量成长，但需要额外续牌来源 | 把“存在循环”误认为“不会断牌” |
| 已有收割条件 | 阿离守约 / 玄策；海月为有转移条件的后续分支 | 棋手收益来自指定英雄击杀，适合早兑现的主核 | 没有等级转移条件就拆旧主核 |

常小娥马瑶、瑶妹李信仍然是重要基准，不能因为它们常见就否定。新的价值应该体现在对它们的改造与选择条件上，而不是为了冷门故意提高成型成本。

**我最愿意先验证的两个改进方向：姜导逐鹿的“多次小成长”，以及三分施法体系中大乔的“先训练、后转型”。**它们可以在三四阶阶段形成工作结构，且不必以双五阶和特殊装备作为开局计划。

## 2. 先固定规则，避免整个分析建立在错误前提上

官方基础规则是六人、每位棋手初始 60 生命；普通商店英雄的基础购买价统一为 3 能量，出售手中或场上英雄通常得到 1 能量。品阶主要改变可获取窗口和卡牌功能，不能按其他游戏的“一费、五费价格”算成本。升级提供天赋，部分等级增加上阵人数，六级解锁棋手专属。[官方新手指南](https://wxq.qq.com/cp/a202609xszy/index.html)

同时区分以下事件：

| 事件 | 实际意义 | 容易造成的错误 |
|---|---|---|
| 使用英雄牌 | 打出一张牌 | 拖动现有英雄换位置不等于重新打出 |
| 合成 | 同名牌与场上英雄结合 | 买一张新英雄后卖出，不会凭空获得合成收益 |
| 登场 | 该牌被使用后触发的卡牌效果 | “触发登场”与“打出英雄牌”不是同一个事件 |
| 整备 | 回合开始触发，部分牌可额外触发 | 回合中刚买到朵莉亚，不会追溯本轮已经结束的整备 |
| 开团 | 战斗开始触发 | 不能随意用唤醒或临阵磨枪代替 |
| 牺牲 | 具有相关效果的英雄阵亡触发 | 一个英雄拥有多个牺牲效果，不等于李信必定按多个死亡计数 |
| 退场 | 出售场上英雄 | 手牌直接出售不等于退场；效果移除也不能自动按出售结算 |

依据是[官方英雄卡面及关键词](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)。

另有几条必须纠正：

1. **没有普遍适用的存款利息前提。**“存款利息”是一个明确天赋；有它时要考虑档位，没有时不照搬其他自走棋的存钱公式。
2. **觉醒和等级是两条轴。**觉醒改善卡牌效果；10 / 40 / 100 级改善战斗技能。不是所有觉醒都简单翻倍，也不是升到 100 就自动觉醒。
3. **夺取是转移，不是创造等级。**猪八戒、公孙离的夺取会削弱供体。必须核查是否把保护位从 100 吸到 90、从 40 吸到 30。
4. **临时等级不等于永久收入。**明世隐有可保存容量，不能把战斗中 999 的截图直接当成下一回合的真实等级。
5. **没有可证明的统一“无限复活”。**花木兰当前是每使用五张古币增加一次复生；规则限定单英雄每回合最多复活十次。
6. **公开卡池不是完整获取清单。**王维由天赋引入，不在普通 85 英雄顶层列表；图腾和召唤物也不能遗漏。

## 3. 评价一张牌，要同时记五本账

### 3.1 能量账：免费刷新不等于免费购买

普通英雄买入再卖出的直接净支出是 2 能量，另计搜牌。拿到一张免费英雄后打出再卖出，才可能同时获得出牌收益和出售收入。

所以：

- 有姬小满并不代表买卖不亏钱；她解决搜索成本，没有自动返还买牌成本。
- 有小妲己并不代表免费拿来的英雄会推进“购买四张牌”的任务。
- 白歌需要合成；马可需要打出三阶及以下英雄。两者都不能按“拿到一张牌”直接记一次收益。
- 镜能减少关键牌搜索的不确定性，但技能使用四次后会涨价，要比较当下复制价格与其他取得方式。

一个普通梦奇的过牌例子：买入 3，部署后卖出得 1，退场给一阶兑换券；如果兑换到普通英雄并把它卖掉，另得 1，直接净支出约 1。若把新牌留下合成，则这 1 能量没有回收，但得到合成与阵容收益。不能同时把“卖了它”和“留它合成”都算进同一次回本。

涉及转瞬牌时，不能套用普通手牌出售收入。公开词典将转瞬解释为到期销毁、出售不获能量；其部署后出售口径需按客户端确认，本文的收入演算不预支这部分。[规则整理及来源说明](https://www.wxqwiki.com/mechanics)

### 3.2 事件账：同样十级，拆成十次可能更值钱

姜导的封神一瞬对永久升级事件追加一级。这意味着两种增长结构的差别很大：

- 一次 +10，按一次有效永久升级计算，变成 +11。
- 十次各 +1，按十次独立有效升级计算，变成总计 +20。

芈月、孙膑、镜、张良等不断产生小额成长，因此比单纯的大额升级牌更能利用这个棋手。这个判断依赖触发被引擎视为独立升级事件；没有假设额外的一级会继续触发自己形成递归。

### 3.3 接收账：随机目标与装备最多都是可管理的资源

同样增加一个人，可能出现完全不同的结果：

- 让张良觉醒后的全体收益多覆盖一个有效战斗单位。
- 稀释常小娥的随机助力，或裴擒虎取样的平均等级。
- 稀释日落海核心分配，使主核跌出 100 级。
- 抢走芈月的装备最多目标、瑶和明世隐的最近目标。
- 给曹操增加一个登场候选，使甄姬不再稳定被触发。

因此，不能只比较“这一张强不强”，必须比较“加上它后，已有体系哪些收益变了”。

### 3.4 时间账：未来收益按还能经历的有效回合计算

一个成长位每轮提供 4 级，还能工作四轮，理论供给是 16；只剩一轮，供给就是 4。更严格地写：

`预期未来收益 = 各未来回合仍存活且引擎仍在场的概率 × 该回合实际收益之和。`

这不是要求玩家当场算出概率，而是提醒：低血量局必须降低慢成长的估值。能多活一轮的保护牌，还能让现有整套引擎多工作一轮，它不只是“肉一点”。

### 3.5 兑现账：谁先出手，比最终面板更重要

把失败分成四类，下一轮才能买对东西：

1. 主核没出手就死：保护、站位、复生、启动。
2. 出手后被控到死：免控、驱散、压制对策。
3. 持续输出但打不动：减抗、重伤、伤害类型、目标选择。
4. 战力尚可但成长跟不上：引擎觉醒、永久成长、牌流。

不要用“再加等级”同时回答四种完全不同的问题。

## 4. 九条路线共用的回合框架

社区首发机制资料常见的经济节奏是：R1–3 每轮 6 能量、R4–7 为 8、R8–11 为 12、R12 起为 15；升级经验档位 7 / 13 / 17 / 23 / 27，常规拍卖在 R3、R7、R11 战斗后衔接下一备战阶段。该资料明确来自八月体验服，因此以下仅把它作为规划时间轴，**实际能量、拍卖与升级费用读当前界面**，不拿它冒充完整 S1 官方概率表。[原作者机制说明](https://www.taptap.cn/moment/845302016388368810)

下文 R4 / R8 / R12 的拍卖决策都指相邻的那次拍卖，不因界面把它标为上一回合而改变打法。

每轮按这个顺序做：

1. 先看对手：是否能撑到主核启动，是否进入下一次大败就出局的范围。
2. 核对本轮已结算的整备收益、手牌到期和技能限制。
3. 先把接收器、装备数量和最近目标摆好，再打资源牌。
4. 先花确定能补齐功能的费用，再决定可用于刷新和升级的余额。
5. 在结束前留出足够时间停止刷牌、部署觉醒回手牌、恢复站位。

搜牌上限不要写死为“这回合搜十次”。设现有能量 E，必要保护/技能预算 B，准备购买的关键牌 k 张，刷新单价 c：

`可承担刷新次数 ≤ floor((E − B − 3k) / c)`。

这里只是现金上限，不是建议一定全部刷完。假设 E=12，留 3 给保命牌，准备买两张关键英雄，那么可用于付费刷新只有 3。找到一张牌后，要按新的缺口重新计算。

拍卖的最高出价同理：现有能量减去本轮必须保留的买牌和稳血预算。不要提前花掉尚不知道数额的分红，也不要为了抬价意外买下无用拍品。

## 5. 路线 A：姜导逐鹿，以镜为默认输出，廉颇为条件分叉

### 为什么这条线值得优先研究

最小工作结构是：**镜＋芈月＋孙膑＋西施＋能扛住的前排**。核心在三阶以内；不要求鲁班七号、鲁班大师或嬴政到齐才能开始。

镜的基础法力上限为 20；孙膑把每三次施法转成永久成长；芈月把使用效果牌转成装备最多的逐鹿英雄的等级；镜自身也按效果牌次数成长。姜导再放大多次永久升级。西施减蓝可以降低镜的启动门槛。数值和触发条件见[官方英雄数据](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)。

这里最重要的投资顺序是：**让芈月准确喂到镜 → 解决镜活着出手 → 再提高每轮效果牌数量**。

### 一个可以核算的购买决策

假设镜、已觉醒芈月在场，镜装备数唯一最多，场上另有河洛英雄可接古币。商店出现两张古币多多，每张成本 2。

花 4 能量，手动使用两张古币多多和产出的四张古币，总计六次效果牌使用：

- 芈月给镜 12 永久等级。
- 普通镜自己的效果再给 3 级；觉醒镜给 6 级。
- 河洛接收者从四枚普通古币另得 8 级。
- 不把自动使用古币的争议计入，这里只统计手动使用。

也就是不算姜导、主角任务和其他效果，已可形成“镜 15 / 18 级＋河洛 8 级”的局部产出。若封神一瞬已经给镜，而且两条被动的升级分别结算，则镜约为 24 / 27 级。这个算例说明：**同一张效果牌可以同时供给跨阵营的两个核心，不必为了‘逐鹿纯度’立即卖掉好用的程咬金。**

反过来，没有芈月、没有可用河洛目标、或者下一战镜根本活不到输出，这笔购买就失去上述价值。[效果牌与成本](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_2.js)、[姜导卡面](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_16.js)

### 觉醒先后不是“主 C 永远第一”

若未来预计还能打 n 张效果牌：芈月觉醒相对普通状态多给目标 n 级；镜觉醒相对普通状态多给自身约 floor(n/2) 级。单看这条备战成长链，芈月的额外产出约是镜的两倍。因此在两者觉醒代价接近、镜已经能作战时，先芈月有充分理由。

若镜离 100 级只差一次投入，或者当前生存问题只能靠它的战斗节点缓解，则先过节点。孙膑觉醒看预计施法次数；西施觉醒看现有推演是否已经足够，别为了多减已经无用的蓝条继续投入。

### 逐回合决策

| 回合 | 主动作与拿牌 | 来牌不顺、压力变化时 |
|---|---|---|
| R1 | 拿能独立作战的低阶前排；自然来的孙膑、曜可留。 | 不为未来镜刷新到没钱部署前排。 |
| R2 | 补当前战力与首次升级天赋；向第一个 25 级英雄推进姜导任务。 | 任务可以由过渡单位完成，封神一瞬不必立刻交给它。 |
| R3 | 留本轮必须的战力支出，第一次拍卖优先镜、芈月、西施中真正缺失的一环。 | 手上廉颇、墨子明显更齐，可保留炸盾分叉。 |
| R4 | 商店可见三阶后明确主核；镜与芈月都到手才集中装备和封神。 | 只有镜没有芈月，先按刺客战力用，少买纯效果触发。 |
| R5 | 芈月目标设为唯一装备最多；孙膑放安全位；西施的当轮推演给主核。 | 镜跳落点会被集火，先调整镜像落点或补前排。 |
| R6 | 用廉价、有效的效果牌推进主核 40 / 100；开始比较芈月觉醒。 | 前排崩溃时，停止把全部能量变成镜的面板。 |
| R7 | 看第二次拍卖可否补决定性的四阶牌、觉醒素材或保护。 | 不为挂一个鲁班大师把中期经济抽空。 |
| R8 | 镜线补保护；廉颇线只有拿到扁鹊、稳定盾循环后才真正切入。 | 镜已经有封神和成长时，不为新来一张廉颇重练。 |
| R9 | 已有整备河洛前排可继续供币；孙膑的价值用实际施法次数判断。 | 孙膑总是先死，就先移位；无法保护才考虑换即战力。 |
| R10 | 缺续航、免控且六级可承受时，评估姜导专属。 | 不把“上六”当成必然比一张保命牌更值。 |
| R11 | 保留关键拍卖预算；只囤下轮确有使用目标的非转瞬资源。 | 两败内可能出局，减少纯未来收益。 |
| R12 | 选择能解决当前死因的装备或效果；复生优先给真正主核。 | 对压制不能仅依赖普通免控。 |

| R16+ | 逐场复盘第一次阵亡和第一次施法，针对性换一位。 | 成型后的调整以保留已投入主核为前提。 |

### 廉颇分叉的真实要求

廉颇＋墨子＋扁鹊成立的关键不是盾厚，而是**活着反复生成并打破护盾**。墨子把破盾次数变成永久最大生命，扁鹊再按最大生命输出。廉颇自己的技能提供自身盾；卡牌效果提供的是其他英雄的盾，不能把两者混写。

扁鹊普通 / 觉醒的一次有效破盾伤害系数为承盾者最大生命的 10% / 20%，有一秒冷却。因此最大生命 10,000 的单位，一次有效破盾对应原始法伤 1,000 / 2,000，仍要经过伤害规则，且不保证每次新盾都立即击破。

盾太厚可能降低破盾频率；盾太薄但本体扛不住则直接断链。最优点是可持续破盾，不是单独最大化盾量或挨打次数。无法确认冷却是每单位还是全局前，不把多前排爆炸直接相加。

这条线路已有玩家原型；本文新增的判断是以接收目标、事件数和回本期决定分叉，而不是宣称发现了全新阵容。[原型参考：村雨的炸盾分析](https://www.iyingdi.com/tz/post/5645567)

## 6. 路线 B：训练大乔，再接马超与诸葛亮的施法体系

### 成长资产是永久减蓝，而不仅是英雄等级

大乔基础法力上限 45，普通状态每两次登场触发减 5，觉醒后每次登场减 5。若目标面板为 10，纯卡牌效果从 45 降至 10，需要七次有效减蓝，即普通约十四次登场，觉醒约七次；若已有装备减蓝，所需次数减少。10 是否为最终下限以客户端为准。

这意味着一张打出后并不留场的孙尚香、赵云、貂蝉，仍可能留下持久的训练收益。曹操可在回合开始额外触发登场；等大乔训练完成，早期的训练挂件可以让位给战斗组件。

最小战斗结构：**低法力大乔＋刘禅＋马超＋稳定前排**。四阶诸葛亮是后续输出出口。孙膑可以把高频施法变成永久等级；明世隐是另一个保存临时收益的选项，两者不要不问人口就同时塞入。

四格只是功能骨架，实际放五至七人要读当前人口和已取得的天赋。刘禅能兼任前排时，空出的预算可补保护或施法来源。所谓“R6接入”等，是在相应品阶已可获得时的决策目标，不保证某轮必能买到牌。

诸葛亮每次收到其他英雄施法，会获得法力和临时等级；刘禅给施法者临时等级。因此辅助多施法一次，可能同时推进输出、控制、诸葛亮成长和刘禅成长。[官方英雄规则](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)

### 我不接受“自然法杖让马超永动”的直接结论

马超基础蓝条 60；自然法杖对近战每消耗 80 法力产生一次变猪控制。先只假设变猪算一个有效控制事件，觉醒马超由此得 30 法力：长期平均回流比例是 30/80=37.5%，小于 100%。

所以这件装备能改善循环，**单独不能证明循环自给自足**。其余法力仍需瑶、大乔、刘禅控制、普攻或其他来源供给；施法动作、控制免疫和法力溢出还会限制收益。若给远程施法者，法杖按 40 法力触发，需要另算，不能把近远程条件混用。[自然法杖当前卡面](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_4.js)

### 群战能连放，不代表残局仍能连放

瑶40级后每两秒随机攻击至多两名敌人，并造成眩晕。若每个目标各算一次有效控制，觉醒马超在有至少两个可控敌人时，每两秒最多从这一来源得60法力；只剩一个可控敌人时，则最多30。对60蓝条的马超，相当于这一来源理论上从每两秒一次施法的供给，降为每四秒一次。这里尚未扣除溢出、控制失败及施法锁蓝，也没有把其他回蓝加进来。

因此，残局停机不一定是等级不够。需要检查剩余控制目标数量，再决定是否用固定回蓝、第二控制源或回收枪的生存装备补缺口。把群战最高触发频率套到最后一名敌人，是很容易误判的地方。

## 7. 路线 C：张良的跨阵营开团成长，不以双五阶为前提

### 为什么普通开团射仍有值得深挖的地方

张良的触发看己方单位的开团效果；觉醒后收益覆盖全体英雄，不局限于大河。因此公孙离、艾琳、雅典娜、太乙等，也可以与大河成长部件共同工作。

标准可用骨架：**公孙离＋张良＋云中君＋瑶**，其余按前排与图腾情况补鬼谷子、少司缘、虞姬。没有张良前，不把这几张牌当成完整成长引擎。

举例：场上有公孙离、云中君、瑶、虞姬四个有效开团来源，张良觉醒，则每位在场英雄仅从这部分得到四次 +1。云中君如果也觉醒，穿三件装备的英雄还有相应的装备成长。瑶临时分享装备与云中君开团先后未确认，预算中只先算开战前已经穿戴的装备。

鬼谷子的先知图腾自身也有开团；张良写的是“单位”，所以它也是值得纳入的触发来源，但要核对当轮是否在其他效果结算前存活。特别是同时放刘邦时，不能一边按全部图腾活着算成长，一边又按全部已被摧毁算收益。[英雄与关联图腾](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)

### 少司缘的边际价值，取决于能活着普攻多少次

普通因缘图腾每累计 25 次己方单位普攻，给全体英雄永久成长。若全队有效普攻速度是每秒 A 次，持续战斗 T 秒，粗略触发次数是 floor(A×T/25)。这只是忽略走位和死亡的计数模型。

所以攻击速度、存活时间和额外普攻单位，都可能提高它的收益；但新增召唤物如果被大司命的往生图腾吸收，不能继续算作场上的普攻来源。高等级少司缘不是唯一投资，保护图腾和维持有效攻击时间也能提高成长。

## 8. 路线 D：马可同阶养成，猪八戒是主要出口之一

### 为什么同阶结构比“只找猪”更重要

马可每打出四张三阶及以下英雄给宝藏。猪八戒在三阶及以下英雄合成时，给与其同阶的英雄成长。因此如果主要养成成员是猪八戒、刘禅、明世隐、瑶、姬小满等三阶，每次有效三阶合成可能同时推进：本体合成、同阶成长、马可宝藏进度。

但没有合成就没有猪的这部分收益；没有打出就没有马可进度。把“买一张、马上手牌卖掉”当作刷全部被动，是错误的。

觉醒猪八戒在五名合格三阶英雄同时在场时，一次三阶合成的同阶效果提供总计约 10 级，而非只看主核 +2。之后通过安全的夺取把部分低价值等级集中到主核，是第二步，不能重复当作新增十级。

### 复制宝藏的手牌管理

冰曜宝石镜复制手中随机一张非觉醒英雄牌。若手上三张合格牌只有一张猪，不能按“必出猪”估值；在确实希望复制猪时，先合理处理其他候选，把目标池缩小。不能为此把正在等关键牌序的高价值英雄无脑卖掉。

马可的终极宝藏有多个结果。当前关联卡里的吸睛自拍是随机三张不同的场上英雄牌，不能当成“指定三张猪”。[马可及宝藏关联数据](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_16.js)

## 9. 路线 E：日落海先积累，再压缩；额外研究跨阵营整备

### 第一阶段：扩大每轮永久产出

自然来的狂铁、亚连、安琪拉、米莱狄提供整备底座；朵莉亚把整备变成额外成长；雅典娜增加日落海整备触发机会；海诺增加核心每次增长的幅度。

朵莉亚的接收条件是己方英雄触发整备，并非只限日落海。因此已有程咬金、李元芳等高质量过渡牌，不必仅为阵营纯度立刻出售。韩信又能从整备或开团中取得永久成长，构成跨阵营出口。

但雅典娜的抽取对象明确限定日落海；露娜才可额外触发其他阵营的整备。**“朵莉亚能吃到”不等于“雅典娜能触发”。**

### 第二阶段：把已积累的核心转换成战斗节点

普通核心分配是平均给日落海英雄，单人最多得到核心的一半。设核心等级 C、合格人数 n，忽略取整：

`每人获得的临时等级 = min(C/n, C/2)`。

具体局面：核心 180，艾琳真实等级 35。

- 六名日落海：艾琳约 65，未到 100。
- 三名日落海：艾琳约 95，仍未到 100。
- 两名日落海：艾琳约 125，可以越过 100 节点。
- 只留艾琳：仍最多约 125；不会变成 215。

因此决赛时可能值得把一个已失去成长价值的日落海挂件换成非日落海保护位，使艾琳越过门槛。但不能为了压缩，把唯一前排和回蓝都卖掉。若已有高等级苏烈，通常比临时购买一级坦克更适合作为替换候选。

这个数值转换不依赖艾琳觉醒或五阶到场，是这条路线最值得掌握的真实决策。[核心规则及艾琳技能](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)

## 10. 路线 F：白歌三分倒转，先修正随机池再谈上限

### 回路存在，但并不天然无限

结构：露娜登场 → 曹操整备 → 甄姬登场 → 获得新的登场英雄牌；小乔把过程中发生的登场转成成长。

真正要分别检查三个池：

1. 露娜能选到的整备英雄池。
2. 曹操能选到的三分登场英雄池。
3. 甄姬能发现的新英雄牌池。

例如只保留曹操、孙悟空两个有整备效果的英雄，普通露娜触发两名合格英雄时就能覆盖这两者；若额外加入程咬金、西施、裴擒虎，曹操被选中的确定性就下降。该结论以“从有该效果的合格英雄中不重复抽取”为前提，客户端若采用别的选取口径须改算。

曹操觉醒选择两个目标时，只保留甄姬和周瑜两个三分登场目标，可避免孙尚香、赵云、貂蝉抢走甄姬的位置。小乔本身是接收器，没有登场效果，不属于这一候选池。

但是甄姬下一张仍然随机。即使假设只有九个等概率候选、三选一不重复，指定某个目标的出现概率也只是 3/9，而不是 100%。九仅为算例；实际候选池、禁用和抽取权重未完整核实。

所以续航要来自白歌复制、已有露娜库存、唤醒/临阵磨枪、合成锦囊、慕名而来等额外来源。不能把一条成功路径乘无限次。[官方卡面](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)、[常见固定模板原文](https://www.taptap.cn/moment/845307409969710878)

### 局部模拟：三张资源牌怎么用

给定场上曹操、甄姬、小乔、露娜，手上唤醒、临阵磨枪、露娜各一张：

1. 先看甄姬是否觉醒、曹操是否有其他候选。如果没觉醒且发现能力弱，先提高关键质量通常比多启动一次更重要。
2. 缺回牌时，唤醒可以直接作用于甄姬；这绕过了露娜和曹操前面两次随机选择。
3. 曹操的池已经干净时，临阵磨枪打曹操可触发甄姬，同时可能带周瑜成长。
4. 露娜保留为扩展触发和合成资源；若能帮助觉醒或完成白歌计数，再按需要先打。
5. 新拿到的牌若能维持下一次关键触发，价值高于只加少量当前等级；若已经快到备战结束，顺序反过来，先把战斗牌部署完整。

同样三张牌，不一定一律先露娜。这取决于你当前缺的是回牌、触发密度还是战斗质量。

## 11. 路线 G：阿离，优先让早期收割兑现，海月转型要有交接工具

### 守约与玄策是两种不同的低成本起步

守约的关键是牺牲英雄阵亡后降低当轮法力上限，配合高倍率狙击。用铠、盾山、钟馗等逐步增加供给，功能可自然过渡到后期。玄策则依靠切入和击杀推动自己的整备成长，也适合阿离对指定英雄击杀数的需求。

阿离的伞应该保护当前能够取得击杀的英雄。不是看见五阶更高就立刻交接，因为秘技推进需要实际击杀，而且旧主核已有等级、装备适配与其他专属投入。[阿离规则](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_16.js)、[官方玄策方向](https://www.taptap.cn/moment/849611051111550844)

### 海月的正确增长模型

海月 40 级后施法获得 `50＋10%最大生命` 的盾；其被动把获得护盾的 25%转成最大生命。在只算这一个来源、盾正常获得的理想局部模型中：

`H下一次 ≈ 1.025 × H本次 + 12.5`。

不是每次变成 1.25 倍。护命灵珠用的是基础生命，不应误写成当前最大生命再连续复利。被动没有写永久，这里只分析当场战斗内的增长。

结论是：**海月不仅需要高初始生命，还需要多次成功施法的窗口。**回蓝、保护、伞落点、控制对策，与等级同样重要；它生命恢复受限制，也不该照搬其他法坦的吸血方案。[海月与装备当前卡面](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)、[装备](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_4.js)

## 12. 路线 H：瑶妹李信，围绕死亡顺序与保存容量优化

### 少人独吃与多人牺牲是两个冲突目标

李信需要牺牲英雄的有效死亡次数；小鹿奉献需要分配临时等级。这两者不是“人口越少越好”或者“牺牲越多越好”就能统一。

对普通李信，存活期间 k 次有效死亡给 7k 临时等级；觉醒为 14k。铠另外给河洛临时等级。明世隐再保存其中一部分。

假设当轮李信能拿到 80 临时等级，而小明可保存容量只有 8：增加到 120 临时等级，未必增加永久积累；增加小明容量、并保证李信活着接收，可能更值钱。反之保存容量已经 40、实际只有 14 临时等级，则继续买小明不是首要问题。

小鹿奉献的完整分配目标集合、死亡/复生后的结算先后没有从公开规则得到完整答案，所以不以“辅助先死光，李信必独吃全部小鹿等级”作为整条路线的前提。

## 13. 路线 I：常小娥，先集中到节点，再选择马瑶或老虎

### 四人不是开局到结尾都必须遵守的禁令

常小娥的小菟助力会随已助力次数增加。四目标送福使少量有效英雄更容易被覆盖；因此培养无关过渡位有长期稀释成本。

但这个成本必须与失血比较。多上一个前排能让主核完整输出、少掉一轮大血时，它可能比集中多得若干等级更值。正确的问题是“这一位换来的战斗窗口，是否超过稀释的成长”，不是“超过四人就错”。

成长顺序优先看节点：苏烈 40 的复生、瑶 40 的控制、马超 40 的暴击收枪、马超 100 的多段突袭、瑶 100 的属性分享。只给马超加等级，可能让提供法力的控制源始终没有启动。

### 一处热门攻略说法与当前卡面冲突

普通总等级达到 50 / 150 / 375 的秘技，与六级后“通过小菟助力提供 65 级”的进度是不同条件。根据当前卡面，不能直接认定众星闪耀给全队加 70 级就必定填满六级追加送福任务。它可以提高全队实力，是否计入该任务必须看客户端计数。本文不采用这项未经确认的额外收益。[常小娥卡面](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_16.js)、[提出相关说法的玩家文章](https://www.taptap.cn/moment/850877042747509094)

## 14. 不应遗漏的五个条件分支

### 14.1 丝绸之路＋零钱兑换：这是牌源候选，不是已经证明的无限钱

丝绸之路让出售古币获得河洛英雄牌；零钱兑换把获得的古币换成多枚不能提供等级的破损古币。如果破损古币确实被丝绸之路视为古币，那么一个原本的精致古币可能被拆成多个抽牌入口。

必须分别确认：破损币是否触发出售古币条件；它是否具有转瞬限制；生成英雄是否可正常出售；“获得”和“自动对英雄使用”是否都会被兑换拦截。

即使全部成立，也存在明显代价：放弃古币直接等级，把牌流转化为合成、出牌或出售收入。木兰可能喜欢使用次数，却与把所有古币卖掉发生竞争。不能一枚币既按“出售得牌”算，又按“使用得复生”算。[天赋原文](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_8.js)

### 14.2 能量改造：从临时等级路线转成自动触发路线

核心每 30 级换一次回合开始的随机登场/整备触发，最多一百次，但核心不再分配临时等级。核心 300 时理论产生十次触发，具体收益依赖候选池。

若目前艾琳完全依赖核心分配，这个天赋会立刻改变她的战斗等级；只有在自动触发能提供足够永久成长、牌流或其他战力时才值得切换。可考虑小乔、朵莉亚双接收，但它们消耗人口，随机事件还会在多个来源间分散。

它不是“日落海更强的通用金手指”，而是换了一台引擎。[能量改造](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_8.js)

### 14.3 能源置换：成熟核心可以承担的经济转换

每轮核心少 20 换 10 能量。在两个日落海接收者、未碰其他上限时，损失相当于每人少 10 临时等级；十能量能否换回更好的永久成长和战力，取决于已有牌流。

若艾琳因此从 105 跌到 95，成本包含失去 100 技能节点；若她本来 240，损失的边际影响可能小得多。要比较节点，不只比较“10 钱换 20 级”。[能源置换](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_8.js)

### 14.4 王维：把整备/牺牲次数再加工的跨阵营候选

红豆之托提供王维，并在场上总等级达到 100 / 200 / 400 时继续给牌。官方公布的两个效果牌方向分别利用牺牲次数提供定向等级、利用整备次数提供全体等级；王维本身还有开团与控制，因此理论上可以接张良与马超。

值得研究的是：把他插入已经拥有整备或牺牲的阵容，让已有事件多一层产出，而不是围绕一张天赋专属英雄从零重建所有队伍。

特别需要核对**开团获得牌的实际可用时点、转瞬保留方式和累积计数口径**。不能把开战才生成的牌提前算进同一轮备战成长。本次卡库未完整暴露两个效果牌的当前字段，具体数值只参考官方 8/28 公告，尚未作 S1 客户端确认。[官方王维发布说明](https://game.xiaomi.com/viewpoint/1683157310_1787832000296_16)

### 14.5 海月吃盾：可接廉颇/刘邦，但别忘了减少人口后的功能缺失

廉颇给其他英雄反复提供盾；刘邦 40 级后可向身边友军提供盾。这些盾可成为海月增加最大生命的来源，因此炸盾和海月之间存在交叉研究空间。

但是增加一个喂盾位，也意味着少一个回蓝、复生或等级来源。海月能否安全持续施法、盾是否实际获得、她阵亡时的生命上限口径，决定最终效果。在缺本体等级和保护时，不值得仅为了理论复利去凑两个新四五阶。

## 18. 三个不靠假设胜负的完整决策场景

### 场景一：R6，姜导镜，十二能量该买什么

给定：镜已能接战；芈月差一张觉醒；手上已有六次效果牌使用机会；前排尚能争取输出；商店有芈月、镜、一个普通升级效果和保护选项。

决策：先买芈月 3 能量完成觉醒并部署，整理装备让她只喂镜，再打手里的六次效果。相对于芈月不觉醒，这批现成手牌立即多给镜六级。若买镜仅增加一次普通合成、尚不觉醒也不跨节点，当前边际收益可能更低。

接下来观察剩余九能量：镜若只差少量到 100，补节点；若上轮死于首次集火，保留保护费用；余量才考虑刷新。这里没有因为理论成长漂亮就花光全部资源。

变化 A：镜只差最后一张觉醒，且它刚好跨 100，则镜可能反超。

变化 B：芈月觉醒回手后忘记重新部署，整段预期收益消失。

变化 C：镜没有最多装备，升级喂错人，这笔交易的结论失效。

### 场景二：R12，日落海一位换人让技能发生质变

给定：核心 180，艾琳真实 35，三名日落海在场；另有成熟非日落海前排可以继续使用。当前艾琳开战约 95，未到 100。

方案 A：保留第三日落海，通过定向成长给艾琳至少五级。适合第三人仍承担不可替代的承伤/水域功能。

方案 B：把低收益第三日落海换成已有非日落海保护，艾琳约到 125。适合被换掉的只是慢成长位，而且新保护确实能维持战斗窗口。

方案 C：只留艾琳，仍约 125，但失去第二日落海的功能，没有额外分配收益。除非另有明确原因，通常没有必要为了“独吃”这么做。

然后再看对手：若是压制锁核，跨 100 仍未解决出手问题；若主要是近战追击，艾琳的新技能范围可能明显更有价值。

### 场景三：R10，白歌循环断了一次，是否继续搜

给定：露娜、曹操、甄姬、小乔已在；甄姬未觉醒；手里只剩一张唤醒；现有能量九；下一战需要至少一张保护牌，预算三。

先留三能量保护，不把九全部用于盲搜。检查曹操和露娜候选池，把不必要的干扰者在不损失关键战力的前提下处理。唤醒直接给甄姬，避免再经过两层随机。

如果回来的牌是有效启动件，继续有限连锁；若只是成长牌，打完得到成长后停止，把战斗阵部署完成。剩六能量可用于一张明确关键英雄加有限刷新，或者直接购买现成战力。

变化 A：甄姬差一张觉醒且商店已给出，优先买它；不先刷新把确定性刷走。

变化 B：只有一个动作的时间，优先把觉醒主核放回场，不再启动长动画链。

变化 C：生命足够、下一轮有已知白歌资源窗口，可以保存非转瞬启动资源，下一轮再发动；没有必要每轮把所有牌全部耗尽。

这些场景模拟的是可复核的资源与决策分支；没有虚构具体伤害、每场掉血或抽牌结果。

## 20. 哪些结论已经足以改变实际打法

1. **在效果牌密度高的逐鹿局，优先比较芈月觉醒，而不是默认所有资源先追主 C 觉醒。**
2. **大乔的永久减蓝应被当成早期可投资、后期继续使用的资产。**训练完成后，让训练位退出，由战斗位接替。
3. **日落海后期的有效换人可以比再买几十级更重要。**尤其在分配人数改变后跨越 100 节点时。
4. **三分倒转要先管候选池，再管牌数。**不必要的触发来源可能让投入效率下降。
5. **马可刷牌需要同时区分购买、打出、合成、场上出售。**少任何一环，都可能让所谓回本变成持续亏损。
6. **李信、海陆空、海月都不能只看最终面板。**分别检查死亡顺序、复制容量、施法次数。
7. **转换核心之前，先找到实际的资产交接工具。**三分换帅不支持无阵营猪直接转吕布，随机遗志也不保证给指定目标。
8. **旧热门路线的价值不因常见而降低；冷门路线也不因新颖自动值得玩。**应优先选来牌成本低、失败后还能继续打、对当前对手有兑现条件的结构。

本文没有宣布某条新组合“稳定前三”或“必胜”。可以给出的实质判断是：在同等资源下，上述决策更明确地处理了启动成本、事件产出、随机分配与战斗兑现，比只给终局七个名字更能指导一整局。

## 21. 继续往下推：四种值得优先尝试的结构改进

这些方向按“少改动现有结构、尽量使用已经养成的资产”筛选。它们的机制依据与尚需实战确认的部分分开写，不将理论组合包装成已验证的新版本答案。

### 21.1 日落海双核：用安琪拉的伤害次数给莱西奥供弹

莱西奥40级后，烟雾里的友军每次对敌人造成伤害，也会给小火鹰一次充能。安琪拉技能每0.1秒造成伤害，40级增加到三道光辉；嬴政也有密集飞剑。这些英雄原本就要投入法强与输出时间，现在可以把同一批伤害事件再交给莱西奥加工。[英雄技能依据](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)

**适合进入的局面：**已经是自然日落海，安琪拉40以上且能完整引导；抽到莱西奥，有足够核心让他过40；缺的是对单或持续补刀，而非第一排没人站。无需因为他是物理英雄，就把全部法装从安琪拉身上拆走。

**可用结构：**安琪拉＋莱西奥＋朵莉亚＋雅典娜＋成熟前排；剩余位置按回蓝、保护与成长选择。这条线保留三阶法核，四阶提供辅助输出，不要求先出艾琳再转双五阶。

**逐阶段动作：**R1–4按自然整备过渡；R5–7优先安琪拉40和足够承伤；R8–10拿到莱西奥后先核查他的40节点与烟雾是否覆盖实际主核；R11–12比较双核有效伤害与单艾琳方案；R13起如果飞弹供给不成立，就把莱西奥视作烟雾/增攻速辅助重新估值，不能为了设想继续砸钱。

一个便于核对的计数：若烟雾内主核在某段有效输出窗口造成24次被系统认可的伤害事件，卡面对应24次额外充能机会。**既不能直接说立刻多24枚飞弹，也不能套“24÷8＝3枚”**：基础技能的八次普攻与40级的充能是两段不同描述，发射调度、同帧范围伤害是否逐目标计数、最高五/十层储能如何消耗，都必须确认。也不能把30个时间片再乘三道光辉就当成必然90次命中。

与艾琳单核相比，这一分支的潜在优点是沿用安琪拉等级、不集中全部风险于一个输出；代价是多一个分配者和烟雾站位约束。若艾琳只差少量就能到100、而莱西奥怎么都不到40，优先艾琳有更明确的依据。

### 21.2 逐鹿施法加鲸吞：用同一套启动设备增加一种击杀方式

已有镜/廉颇＋孙膑＋西施体系时，拿到鲸吞会给庄周。逐鹿施法达到其要求后，庄周能吞噬敌方最低等级英雄并永久获得部分生命上限；普通每战最多一次，觉醒最多三次。

这不是从零凑“吞噬队”。已有高频施法时，只改一个位置，就让同一批技能同时产生伤害、孙膑永久等级，以及吞噬机会。庄周本身还能驱散和提供护盾，40级后盾期间免控，因而并非完全空转的成长挂件。

**换谁：**优先换当前已无有效产出的曜/老夫子或其他慢产牌位；不先卖掉保证主核第一次施法的坦克，也不先卖掉芈月使下一轮效果牌全部失去接收者。

**什么时候不选：**还没有施法窗口；对手低等级诱饵多而真正威胁只有高等级主核；已经进入最后一轮且其他天赋能直接解决保命。吞噬最低等级与击杀敌方最高等级是完全不同的战斗目标。

**回合处理：**天赋拿到当轮先部署庄周并完成其登场，再触发手中效果牌；之后几轮只在第二、第三次吞噬有现实机会时追觉醒。若战斗结束前根本达不到次数，觉醒上限增加没有实际收益。[鲸吞规则](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_8.js)

### 21.3 张良＋雅典娜＋朵莉亚：同一次开团走两条成长通道

这是比“随便塞一张跨阵营韩信”更具体的混合结构。假设张良、朵莉亚均觉醒，雅典娜普通，场上有两个能够被她选中的日落海整备英雄：

1. 雅典娜开团，张良给全体英雄各1永久等级。
2. 雅典娜额外触发两次整备，朵莉亚给全体英雄再各2永久等级，核心也至少加2。
3. 两张整备牌自己的收益另外结算；如果选中的是普通狂铁、亚连，核心另有2＋1，亚连还给装备最多日落海英雄2级。

于是同一个雅典娜开团，在这个给定条件下产生每名英雄3级、核心至少5级及亚连的定向2级。若场上六名英雄，全体部分为18级；这不是六个单位都要变主核，而是要判断辅助能否因此跨40/100。

**这份收益已明确包含张良与朵莉亚，不能再把它们同一触发重复相加。**若狂铁/亚连觉醒，其效果重复次数与朵莉亚触发之间的事件展开仍按实际规则核查。开团时核心增加能否影响当场已结算的核心分配，也不提前计入上述18级。

**适合棋手：**香香利用有效低阶人数与全队成长；姜导则可让指定主核吃多次升级事件。**不适合硬转：**纯逐鹿镜已经集中封神、装备和技能目标时，为此一下换三四个人会付出更高成本。

**结构代价：**六人中张良、朵莉亚、雅典娜已经占三格；若再放两个整备来源，只剩一个纯输出位置。必须让亚连/安琪拉等来源兼任前排或输出，不能把数学收益最大化成没有战斗功能的队伍。

### 21.4 先训练保存器，再接临时爆发：让明世隐的投资不晚于输出

常见顺序是先堆出极高临时等级，再发现小明只能保存几级。更好的机会是：在已经有曹操/甄姬或唤醒资源的过渡局，利用明世隐本身的登场，先增加保存容量，然后把同一个明世隐留到刘禅施法、李信牺牲或老虎复制的战斗出口。

设小明当前可保存容量为B，主核本轮获得并符合保存条件的临时等级为T，单轮实际保存的上限可按 `min(B,T)` 思考。普通小明额外触发一次登场使容量多2，则本轮边际保存至多为 `min(B+2,T)−min(B,T)`，而非永远等于2；觉醒改为4。若这项容量保留到后续回合，再把各轮边际保存相加。

例如B=8、T=80，普通一次额外登场在本轮最多多保存2，未来三轮仍有充足临时输入时总潜力为8；B=40、T=14时，本轮边际为0。后一种局面应增加输入或战斗时间，不应再独立买一张唤醒训练小明。

**关键次序：**先使用明世隐英雄牌并完成其登场，再增加临时等级供给；连接最近的实际主核；主核换位后再次核查连线。三分倒转后期使用它的好处，是不增加曹操的三分登场候选，也不增加露娜的整备候选；坏处是消耗人口，并增加白歌随机复制场上英雄时的候选。甄姬本来就可能发现明世隐，不因你把他放上场才加入这个全局牌池。

这一方向主要改运营次序，不以发现全新阵容为目标。它的价值是把原来浪费的临时成长逐步留下，同时保留转到不同主核的灵活性。
