# S1 全英雄取舍：为什么留，什么时候换

与《S1深度推演》配套，日期 2026-09-23。以下覆盖官方普通列表的全部 85 名英雄，另列天赋专属王维。它不是强度排行：同一英雄在不同资源结构里，可以从无效人口变成不可替代的组件。

规则来自[官方英雄数据](https://game.gtimg.cn/images/amside/ide_timer/589094_oscard_new_1.js)，表内“选择理由”和“退出条件”是我的推导。10 / 40 / 100 指英雄等级；觉醒另外判断。表中只摘影响决策的技能节点，不复述所有数值。

## 1. 河洛：币、牺牲、临时等级，三个体系不能混为一谈

| 英雄 / 阶 | 值得买入的实际条件 | 投入或保留理由 | 不该继续投入的情况 |
|---|---|---|---|
| 苏烈 / 1 | 需要便宜、能自然积累的前排 | 自身牺牲成长；40 自带复生，100 改善复生质量 | 已有高等级苏烈时，换一级高阶坦克未必升级；反之不为后期节点强刷开局 |
| 李元芳 / 1 | 有明确河洛接收者，或旋刃条件 | 最近目标可管理；40 普攻也叠印记，成长与战斗兼用 | 没有币接收者、只剩一战时，比较它与立即保护的价值 |
| 沈梦溪 / 2 | 当轮可定向打多张效果牌，缺范围法伤 | 减蓝来自“对他使用”，不是全场所有效果牌；40 扩范围，100 控制 | 下轮效果牌密度不足，不能把本轮减蓝当永久资产 |
| 盾山 / 2 | 需要牺牲、古币与抗普攻前排 | 死亡可供守约/李信；100 开战架盾，承伤方式改变 | 太早死导致阵线崩溃，或太晚死导致守约无法启动，都要调整位置 |
| 百里守约 / 2 | 有有效牺牲死亡和物理装备 | 低阶获得高倍率技能；40 击杀后穿透，100 不衰减 | 没死亡供给时不可按低蓝连狙；击杀链不成立时不预支多次穿透 |
| 百里玄策 / 2 | 已能取得击杀，少量闪现英雄 | 上轮闪现击杀成为下轮随机闪现成长；100 击杀狂暴 | 无法击杀或太多低价值闪现目标，会使反馈链变弱 |
| 铠 / 3 | 守约、李信、司空震需要有效牺牲与临时等级 | 自带复生让同一单位可能多次发挥牺牲；100 开战变身 | 临时等级接收者未到位时，不把全部牌面收益算为有效战力 |
| 程咬金 / 3 | 需要前排、每轮手动币和整备来源 | 能接朵莉亚，亦能供逐鹿效果牌事件；100 改善低血续航 | 对手强重伤且前排已经替代，剩余币产出不够支付人口成本 |
| 狄仁杰 / 3 | 古币能稳定定向，装备支持普攻 | 币的次数也永久给攻速；100 普攻转蓝牌并周期控制 | 只来一张五阶不应替换已养成狄仁杰；攻速边际下降时换属性方向 |
| 钟馗 / 3 | 守约/李信缺牺牲来源，或需要改变敌方落点 | 左右一格赋予牺牲；10 开战满蓝，是便宜的目标干预 | 拉来的坦克反而堵住自己主核，需换位置或撤下；不是无条件钩越快越好 |
| 上官婉儿 / 4 | 河洛数量足够，已有币放大器 | 多目标用币接武则天、狄仁杰等；40 穿透多目标增伤 | 少量河洛时觉醒的六目标不一定全兑现；不要凭上限评价 |
| 李信 / 4 | 有牺牲顺序与保护，或献祭之赐 | 7/14 临时等级按有效死亡累积；100 狂暴完美复生 | 最先阵亡、没有死亡供给、没有跨节点路径时，单张李信不是救命牌 |
| 李白 / 4 | 古币密度高，或千金换酒/逐星到手 | 为币附加临时等级；给自己收益更高，100 斩击不可选中 | 斩击总伤害会分摊；没有保存渠道时不要全按永久成长估值 |
| 花木兰 / 5 | 当轮有足够币使用次数，需复生近战出口 | 每五币再加复生；轻剑40可持续攻击，重剑100全场控 | 卖币路线与使用币抢同一资源；按最多十次复活规则预算 |
| 司空震 / 5 | 有临时等级输入，而且本体等级已养起来 | 复制临时成长，100 开战雷霆之王是关键兑现点 | 一级司空震不能承接无限临时等级；复制上限与结算顺序未明时保守算 |
| 武则天 / 5 | 未来还有大量古币可用，或需要持续减回复 | 币每张增幅比一次大额加级更有价值；登场还能产币 | 临近决战、手里无币时，不为“经济五阶”挤掉必要保护 |

## 2. 逐鹿：效果牌收益，与战术次数要分开

|---|---|---|---|
| 曜 / 1 | 预计有大量合成，或逐星天赋 | 放大全队合成等级；40 周期控制，100 自带恢复 | 后期合成已少时，不能只因早期功臣就永久占格 |
| 孙膑 / 1 | 主核确实能高频施法 | 每三次施法永久成长，跨阵营适用；100 有沉默 | 主核根本放不出技能，先修启动与生存；别继续买成长放大器 |
| 芈月 / 2 | 有效果牌量、可控制装备最多逐鹿目标 | 备战成长可定向；40 五仆从让她也是治疗与减抗组件 | 装备并列、成长喂错人；纯物理远程队也要看仆从实际保护谁 |
| 墨子 / 2 | 有可持续破盾来源 | 破盾永久最大生命；40 屏障附带控制，可接马超 | 只有开局一层大盾时，不能按持续炸盾速度估值 |

| 老夫子 / 3 | 有自然合成，且需要承受多次小伤害 | 首次合成给招募；100 恢复次数上限改变 | 没合成不产牌，单次爆发秒杀也不是其最合适的承伤环境 |
| 西施 / 3 | 推演能明显减少主核蓝条，且还有后续回合 | 整备每轮给资源；40/100 牵引控制 | 推演只对逐鹿；不能当作训练大乔的方法 |
| 镜 / 3 | 有效果牌与芈月，能接近并活着攻击 | 低蓝条适合孙膑/刘禅；40/100 增镜像，100恢复 | 被集火而未启动时，继续买纯成长不能解决首轮死亡 |
| 扁鹊 / 4 | 已有血量与反复破盾 | 把盾事件转成邻近范围法伤；100 加减攻速 | 没有破盾循环时，不为“炸盾核心”名字硬追；一秒冷却范围待核 |
| 嬴政 / 4 | 已积累战术且有法装与安全引导环境 | 高频飞剑、40 击杀延长引导；可以研究莱西奥充能 | 多次小伤害未必触发痛苦面具；不能把总伤害当单次伤害 |
| 庄周 / 4 | 需要驱散、40 免控，或拿到鲸吞 | 登场产招募，可接小乔/大乔；鲸吞让频繁施法产生另一出口 | 没鲸吞就没有吞噬；鲸吞即便觉醒也有每战三次上限 |
| 蒙犽 / 4 | 需要效果牌启动和已有物理输出位置 | 登场特训能接芈月、镜；40 降低同目标多弹衰减 | 没成长基础时，买他只是花钱换一张特训，不应虚算整名主核战力 |
| 鲁班大师 / 5 | 已有高等级逐鹿核心，想用傀儡扩大战力 | 傀儡有独立继承/复制规则；40/100 多目标控制 | 傀儡基础等级仍来自鲁班大师，不能自动视作完整主核复制 |
| 鲁班七号 / 5 | 未来还有大量合成，或需要范围重伤 | 每三合成给战术，合成链额外产出；100 全场落地伤害 | 合成量已消失时，不应为了产牌而硬占人口 |

## 3. 日落海：积累核心、分配核心、改变核心用途是不同阶段

## 4. 三分之地：登场训练、施法反馈、战斗节点

| 英雄 / 阶 | 值得买入的实际条件 | 投入或保留理由 | 不该继续投入的情况 |
|---|---|---|---|
| 孙尚香 / 1 | 自然需要过渡与搜索，已有登场接收器 | 刷新可留到需要的品阶；技能50%破物防有辅助价值 | 后期占曹操候选池时，要比较刷新和关键甄姬触发 |
| 曹操 / 2 | 场上有值得触发的三分登场 | 整备转登场，可以同时接朵莉亚与小乔 | 没目标时没有回牌；临阵磨枪不等于稳定指定甄姬 |
| 赵云 / 2 | 需要前排及登场成长，或一身是胆 | 低血技能改善，天赋可改变施法频率；可训练大乔 | 在倒转终局会挤占曹操池，须有足够战力理由才留 |
| 大乔 / 2 | 已有登场资源，未来需要控制/施法来源 | 永久减蓝是可保留的早期投资；控制本身接马超 | 没有低蓝也没有启动装备时，不按理想无限波浪算 |
| 蔡文姬 / 2 | 三分出牌量高，低等级辅助需要补齐 | 给最低三人避免完全失养；40双防与治疗，毒奶分支 | 高主核不一定接到成长；为了奶而围拢会提高范围受击风险 |

| 刘禅 / 3 | 主核高频施法，且需要前排控制 | 施法临时等级跨阵营适用；40减伤、100长眩晕 | 没有施法窗口先解决生存；临时等级别重复计为永久 |
| 貂蝉 / 3 | 三分成长、范围重伤，或起舞/舞力全开 | 一张牌可给三分全体成长并训练大乔；40增加花球 | 登场收益已结束仍留场，必须有减回复或输出理由 |
| 甄姬 / 4 | 需要登场牌源，能给曹操稳定触发 | 觉醒三选一提高修复断链能力；40强化冻结 | 随机获得的牌并非都能续链，不能把每次触发写成净增启动资源 |
| 小乔 / 4 | 登场事件密集，收益接收英雄有效 | 觉醒扩大到全体；40/100多目标硬控 | 纯施法队停止登场后，其成长边际下降，可转战斗辅助 |

| 吕布 / 5 | 成熟三分等级可交接，缺续航/范围重伤 | 开团吸血只覆盖指定三分目标；100全场技能 | 猪不是三分，换帅无法直接交接；靠遗志则有随机与重建成本 |
| 周瑜 / 5 | 登场链已有，或可达到100开局焦土 | 登场全体成长且能被曹操触发；40焦土控、100全场 | 没等级就不等于全场焦土；高成本追他前先看当前链是否工作 |

## 5. 大河流域：图腾、开团、牺牲和普攻的交叉

| 英雄 / 阶 | 值得买入的实际条件 | 投入或保留理由 | 不该继续投入的情况 |
|---|---|---|---|
| 干将莫邪 / 1 | 需要立即输出与装备资源，或阿离早期收割 | 不依赖完整阵营即可工作；40双飞剑改善输出 | 装备是“在场时获得”，转移主核时先核查装备是否随退出撤销 |
| 项羽 / 2 | 有图腾或召唤物需免控，缺开战冲阵 | 牺牲养图腾并给召唤物免控；40减攻速 | 无召唤且仅当坦克用时，应与成熟坦克比较，不为阵营标签硬上 |

| 虞姬 / 2 | 已有图腾，或箭雨天赋 | 开团给大河成长；额外攻击适配普攻体系 | 没图腾时成长消失；低质量虞姬不应仅为一个开团占终局位置 |
| 云中君 / 3 | 装备数量已多，或有开团/闪现接收器 | 全阵营按装备永久成长；40普攻撕裂 | 装备少且不能安全输出时，价值低于表面“群体加级” |

| 瑶 / 3 | 有明确受保护核心、40控制或共享装备价值 | 一个人口同时给护盾、属性、控制、装备副本；100分享属性 | 最近目标错位、首件装备不适配接收者；不是任意装备都可分享 |
| 大司命 / 4 | 牺牲多，往生图腾能工作 | 牺牲给图腾等级和法力；本体40多目标普攻 | 往生图腾吸收低阶召唤物会重构前排和普攻数，不可两头同时算满 |
| 刘邦 / 4 | 决定主动牺牲图腾换自身成长，或需要周期盾 | 40给周围友军护盾，可接海月/炸盾；100破盾伤害 | 不能保留“因缘持续成长、敖隐持续图腾增益”全部收益又算全摧毁 |
| 韩信 / 4 | 场上整备/开团多，或需要收割控制 | 跨阵营事件永久养成；可吃河洛整备＋朵莉亚复合收益 | 新来一张没有继承路径时，不立即替换已养成核心 |
| 东皇太一 / 5 | 图腾成长已有，需保护图腾或针对主核 | 不优先攻击图腾有全局作用；100压制可持续至一方死 | 仍要实际接近目标；压制距离条件与承伤决定是否成功 |
| 敖隐 / 5 | 有多个能活下来的图腾和成长/装备交接 | 每四秒图腾给攻速与临时等级；100双武器 | 不应为了五阶身份卖高等级公孙离；刘邦摧图腾与此方向冲突 |

## 8. 真正会改变构筑方向的天赋，应怎样估值

以下不是全部255项的重复抄写，而是筛出改变资源结构或关键限制的选项。随机装备、经验包、阵营来客等常规资源，仍按当前缺口、存活回合和实际价值比较。

| 天赋或组合 | 改变的机制 | 选择条件 / 操作要点 |
|---|---|---|
| 存款利息 | 才开始有明确存款档位 | 每7能量每轮多1；为了保7少买必要保命牌，未必划算 |
| 中坚力量 / 中流砥柱 | 打出三阶额外等级 | 马可三阶集中收益；买了未打出不计，不能当全卡增幅 |
| 凯旋征召 / 春风化雨 / 买橘子去 | 稳定或条件同名牌源 | 胜利、阵营、位置和两回合延迟分别处理，不视作同等稳定 |
| 慕名而来 / 同路人 | 事件触发返牌 | 返回随机牌，不一定续同一回路；同路人要求本轮同阵营四张 |
| 锦囊妙计 / 乐善好施 | 登场次数增益 | 小乔、大乔、甄姬链可共吃，但“额外触发登场”不自动等于额外打出英雄 |
| 卧龙威势 / 控制感应 | 施法与控制转法力或法强 | 必须摆诸葛周围一格；免控、禁回蓝和站位代价要算 |
| 怒涛 | 三分死亡产生波浪 | 补死亡后的控制；原主核先死时控制不能追回失去的输出 |
| 刻舟减蓝 / 灵泉项链 | 减少循环所需法力或增加外部供给 | 比单加伤害更早跨施法门槛时优先；蓝条下限与技能锁蓝另核 |
| 鲸吞 / 技高一筹 | 逐鹿施法再换吞噬或钱 | 有实际施法量才选；分别有每战次数或每轮能量上限 |
| 罡气护体 | 施法期间生成盾 | 可接墨子、扁鹊、海月，但持续技能和短施法覆盖不同 |
| 复现 | 首张逐鹿定向效果返回一次 | 先打高价值且合条件的效果，不要浪费在低价值开路牌 |
| 智能装甲 / 积极整备 | 专属装备与整备次数联系 | 前者可让整备多触发；后者最多给三件，拿满后不再估长期装备收益 |
| 超级蓄能 | 整备英雄人数影响整备英雄成长 | 支持前期扩整备，后期压缩日落分配则存在目标冲突 |
| 动能灌注 / 积少成多 | 普攻或日落升级反哺核心 | 核对临时等级、逐次累计的口径，不把核心分配递归成无限增长 |
| 定向传输 | 从均分变成优先装备最多，最多200 | 选后重新计算是否还需要减人口；不要照搬两人均分规则 |
| 能量改造 / 光棱塔 | 完全放弃核心等级分配 | 当前输出依赖分配时须先找替代战力；不能当无代价附加收益 |
| 能源置换 / 核心裂痕 | 核心换钱或转出等级 | 先看100级节点和核心剩余量，再看每轮收益 |
| 能量汲取 | 卖英雄的等级进入核心 | 成熟辅助的出售损失与分配收益一起算；不默认其临时等级也可变永久核心 |
| 古币翻新 / 升值 / 武则天 | 提高每张币的等级收益 | 币量大时收益可持续；升值依赖后续胜利 |
| 零钱兑换 | 币拆成更多无等级币 | 偏向使用次数、复生或出售牌源，代价是直接等级消失 |
| 丝绸之路 | 出售英雄产币、出售币产河洛牌 | 能量账与卖币/用币互斥；破损古币兼容未实测不能宣称无限 |
| 一起发财 | 用币给其他各阵营随机英雄成长 | 支持少量跨阵营接收器；不是每个其他英雄都加3 |
| 千金换酒 | 给李白用币积累永久额外施法 | 明确养李白才值；散喂不同人不推进同样次数 |
| 古币机 | 把币使用改为分阶段奖励 | 先两个固定奖励，再随机收益；对机器用币与对主核加级存在竞争 |
| 献祭之赐 / 最终守卫 | 李信输入放大或河洛末位保护 | 献祭敌方触发要求李信觉醒；守卫要真正成为最后河洛存活者 |
| 自我奉献 / 四海来援 / 熊魂附甲 | 给原单位额外牺牲效果 | 李信计英雄阵亡，大司命计牺牲效果，两类事件别混用 |
| 箭雨 / 旋刃 / 双生突袭 | 两人共战改变战斗输出 | 已有其中一人和成长资产更值；抽到天赋不意味着无成本组两名新主核 |
| 兄妹 / 宝盒 | 改变露娜窗口或两核生存 | 与登场倒转是不同胜利条件，可作为现有露娜猴子/铠的战斗出口 |
| 巨像 / 升格 / 生生不息 | 召唤体系获得额外实体或复生 | 存活8秒、品阶4/5、次数五等限制要逐项核对 |
| 破阵战芒 / 小咖秀 / 永不独行 | 奖励低阶英雄或低棋手等级 | 升本、上四阶可能切断条件；不要既算条件奖励又算无代价升阶 |
| 四重奏 / 群英荟萃 / 姜子牙 | 奖励跨阵营/跨品阶结构 | 三者条件不同，单纯“杂技队”不保证同时触发 |
| 战术模组 / 扩编名额 | 增加人口上限 | 可以留空；多一格不是必须多放一个稀释随机目标的人 |
| 三三得三 / 鬼神降临 | 要求三分数量或三分死亡数量 | 四人马瑶无法自动获得全部收益；改变人口后重算 |
| 全副武装 / 重装上阵 | 双装备门槛 | 芈月的唯一最多装备目标与全队双装备存在资源分配竞争 |
| 镜像迷离 | 借对手同名等级 | 对手持有同天赋时失效；不是永久盗级经济 |
| 紧急行动 / 紧急救援 / 防御领域 | 把资源变成可多经营的回合 | 低血成长队可能比再拿一组随机英雄更有价值 |
